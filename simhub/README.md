# SimHub definition

`G Rebels.simdef` and `icon.png` go in, on the machine that runs **SimHub**:

    %LocalAppData%\SimHub\ExternalSims\Definitions\

The app copies them there automatically if SimHub is installed on the same PC
as the game. If your rig is a separate machine — the usual case — copy both
files to that folder on the rig by hand, then restart SimHub.

`IconPath` inside the .simdef is relative, so the two files must stay together.
